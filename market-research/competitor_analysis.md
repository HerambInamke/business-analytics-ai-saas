# Competitor Analysis – AI/SaaS Tools

## Objective
To benchmark AI/SaaS competitors across features, pricing, positioning,
and target customer segments.

## Competitors Analyzed
1. Tool A – AI Marketing Automation
2. Tool B – AI Recruitment Platform
3. Tool C – Workflow Automation SaaS

## Feature Comparison
| Feature                  | Tool A | Tool B | Tool C |
|--------------------------|--------|--------|--------|
| AI Personalization       | Yes    | Partial| Yes    |
| Automation Workflows     | Yes    | No     | Yes    |
| Analytics Dashboard      | Yes    | Yes    | Basic  |
| API Access               | No     | Yes    | Yes    |

## Positioning Analysis
- Tool A: SMB-focused, marketing-heavy
- Tool B: HR-tech, enterprise-first
- Tool C: Tech teams, automation-first

## Key Insights
- Most tools lack strong onboarding UX
- Pricing is opaque in enterprise-focused tools
- Clear opportunity for a transparent, AI-first platform
