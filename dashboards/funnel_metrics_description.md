# Funnel Metrics Framework

## Conversion Stages
1. Website Visit → Sign-up
2. Sign-up → First Login
3. First Login → Feature Usage
4. Feature Usage → Paid Conversion
5. Paid → Active Subscriber

## Key Metrics
- Stage-by-stage conversion rates
- Time-to-value metrics
- Drop-off analysis
- Cohort retention

## Optimization Focus
- Reduce friction in onboarding
- Improve feature discovery
- Accelerate time-to-first-value
